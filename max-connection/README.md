# Max Connection

Lets ChatGPT (web, phone, iPad) operate a laboratory computer — files, terminal, screen,
mouse and keyboard — through [Chat On Steroids](https://github.com/totec448-spec/chat-on-steroids)
and a permanent Cloudflare Tunnel under `akior.io`.

**Experience:** private activation link → download installer → install → approve OS
permissions → connect ChatGPT.

This folder adds an installer and a tiny enrollment service around the existing,
unmodified Chat On Steroids release (MIT). It does not change the Chat On Steroids app
in this repository.

## Install on a new computer

1. On a trusted computer, create an activation link (see *Activation links* below).
2. On the new computer, open the link in a browser and press **Copy activation link**.
3. Download and run the installer from this repository's Releases:
   - Windows (x64 and ARM64): `Max-Connection-Setup-<version>-windows.exe`
   - macOS (Apple silicon and Intel): `Max-Connection-<version>-macos.pkg`
     (unsigned: right-click → Open the first time)
4. Approve the operating-system prompts (Windows administrator prompt for the tunnel
   service; macOS administrator password, then Accessibility and Screen Recording for
   Chat On Steroids).
5. The connection helper opens with ChatGPT. In Chat On Steroids → Settings → Setup →
   step 5 press **Copy** next to each MCP SERVER URL; the helper converts it to the
   permanent `https://mc-<name>.akior.io/...` address. In ChatGPT: Plugins → Add →
   Add custom MCP server, paste name and URL, **No authentication**, Create, Connect.

Re-running the installer on the same computer is safe (repair). It keeps the same
hostname and tunnel.

## What the installer does

| Step | Windows | macOS |
| --- | --- | --- |
| Chat On Steroids | installs pinned 2.1.53 (SHA-256 checked) per user, unless ≥ 2.1.52 is present | same, into /Applications |
| Settings | Local only tunnel mode, *Keep plugin URLs across restarts*, auto-connect, start at sign-in, desktop control for ChatGPT calls | same |
| Identity | random machine id + machine secret (DPAPI) | same (login keychain) |
| Enrollment | redeems the activation code → own tunnel, hostname, tunnel token | same |
| Tunnel | cloudflared 2026.11.0 (SHA-256 checked) as the automatic `Cloudflared` service, restart-on-failure | cloudflared LaunchDaemon |
| Check | public hostname must reach the local app (expects its 404 for a wrong path) | same |

The tunnel route only forwards `^/mcp/` to `http://localhost:<port>` with Host header
`127.0.0.1:<port>`; everything else returns 404. Each plugin URL carries a 43-character
secret path generated by Chat On Steroids; requests without it get 404.

## Activation links

The enrollment Worker (`worker/`) runs on Cloudflare at `https://enroll.akior.io`.

- Codes are 256-bit random, stored only as SHA-256, expire (default 24 h), and are
  consumed atomically by one machine. A machine can retry the same code (interrupted
  install); any other machine is refused. Random codes, reused codes, expired codes and
  brute force (20 failures / 10 min / IP) are refused.
- Codes are created only with `admin/New-ActivationLink.ps1` (or `.sh`) on a computer
  already signed in to the Cloudflare account with wrangler. There is no admin endpoint.
- The Worker holds the only provisioning credential (`CF_API_TOKEN`, limited to
  *Cloudflare Tunnel: Edit* and *DNS: Edit on akior.io*) as a Worker secret. Machines
  receive only their own tunnel token.

### Deploy the Worker (once)

```bash
cd max-connection/worker
npx wrangler@4 login
npx wrangler@4 d1 create max-connection          # put the id into wrangler.toml
npx wrangler@4 d1 execute max-connection --remote --file schema.sql
npx wrangler@4 secret put CF_API_TOKEN           # paste the restricted token
npx wrangler@4 deploy
```

## Uninstall

Windows: *Apps → Max Connection → Uninstall* removes the tunnel service it installed.
Chat On Steroids stays installed. To retire a computer completely, also delete its tunnel
and DNS record in Cloudflare.

## Limits

- The machine must be on, awake and signed in; Chat On Steroids runs in the user session.
- Anyone holding a plugin URL can use that computer's enabled tools. Keep the URLs private.
- Installers are not code-signed or notarized.
